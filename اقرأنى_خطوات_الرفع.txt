ابدأ إديو — خطوات الرفع (الإصدار 6)
=====================================

أولاً: قاعدة البيانات (Supabase) — مجلد 2_Supabase_SQL
1) خذ نسخة احتياطية: Database > Backups.
2) SQL Editor > New query > الصق محتوى الملف > Run.
   - لو شغّلت 001 → 004 قبل كده بنجاح: شغّل الملف الجديد فقط:
       5_run_fifth_005.sql   (دورة المصروف + المدير المباشر + النسخ والاستعادة + التقارير + الأداء + الاستيراد)
   - لو قاعدة البيانات جديدة: شغّل بالترتيب 1 ثم 2 ثم 3 ثم 4 ثم 5.
   مهم: بعد 005 لا تُعِد تشغيل 002 أو 003 أو 004 وحدها. إعادة تشغيل 005 نفسه آمنة.
   الملف إضافى فقط: لا يحذف أى بيانات، ولا يغيّر المستخدمين أو كلمات السر أو المعرّفات أو الصلاحيات الحالية.

ثانياً: الموقع (GitHub) — مجلد 1_GitHub
- config.js هنا هو نفس ملفك (رابط مشروعك + المفتاح العام).
- ارفع كل محتويات المجلد: bundle.js · styles.css · config.js · index.html · logo.png + مجلد vendor.
- انتظر دقيقة، ثم افتح الموقع واضغط Ctrl+F5.

ثالثاً: Google Sheets — مجلد 3_Google_Sheets: لا تغيير فى هذا الإصدار.

بعد الرفع — أول خطوات مقترحة
1) الإدارة > المستخدمون: حدّد «المدير المباشر» لكل مسئول عهدة (هو وحده — أو الأدمن — يعتمد مصروفاته).
2) الإدارة > «النسخ الاحتياطى»: اضغط «نسخة احتياطية الآن» قبل أى عمل كبير.
3) المصروفات > «📥 استيراد ملف المصروفات والعهد»: ارفع ملف «مصاريف مدرسة ابدأ.xlsx» كما هو.
   - النظام يتعرف وحده على كل ورقة: «Ebda Eduo - دمياط» ← مدرسة دمياط، «Ebda Eduo - بدر» ← مدرسة بدر.
   - الورقة = عهدة: قيمة العهدة من سطر «إستلمت مبلغ …»، والبند من عمود «الوصف المقترح»، والوصف من عمود «البند».
   - الأوراق القديمة/لأماكن غير مسجلة (Ebda 2023، PortSaid، الاسماعيلية، تحول احترافى) لا تُستورد إلا إذا اخترت مدرستها.
   - راجع «الاستثناءات» ثم اضغط «استيراد». تنزيل تقرير الاستثناءات متاح. رفع نفس الملف مرة أخرى لا يكرر شيئاً.
   - للأدمن: «مصروفات فعلية معتمدة» = تُحتسب فوراً فى منصرف الموازنة؛ بدونها تدخل دورة الاعتماد.
   - خطأ فى استيراد؟ الأدمن يستطيع «التراجع عن الدفعة» (إلغاء لا حذف).
4) الرواتب > «استيراد بيانات العاملين»: كشف المتعاقدين وكشف الحكوميين/المنتدبين (معاينة قبل التأكيد، بلا تكرار ولا حذف).

الجديد فى هذا الإصدار
- دورة المصروف: مسودة ← المدير المباشر (اعتماد/إعادة/رفض بسبب) ← المراجعة المالية ← التسوية، مع رابط المستند و«عرض المستند»،
  ومنع اعتماد الشخص لمصروفه، وإلغاء/إلغاء اعتماد للأدمن بسبب، وسجل كامل لكل خطوة (من ومتى والملاحظة).
- شاشة المصروفات: صف منظم لكل مصروف + تفاصيل + فلاتر وبحث على الخادم (بما فيها المورد ورقم المستند).
- تقارير ديناميكية: موقف مسئولى العهد · الموازنة · المصروفات · الشامل — مع فلاتر وتصدير.
- الإدارة: أنواع العهد والجهات، التفعيل والتعطيل، النسخ الاحتياطى والاستعادة (بكتابة اسم النسخة للتأكيد + نسخة أمان تلقائية).
- استيراد ملف المصروفات والعهد بضغطة واحدة (إنشاء العهد، ربط البنود والشهور، اكتشاف التكرار، تقرير الاستثناءات).
- الأداء: البحث والتقارير والتجميعات داخل قاعدة البيانات، ولوحة بداية خفيفة. نتائج اختبار الحمل الفعلية فى
  5_Source_Code (docs/PERFORMANCE_v6.md): لم يتحمل خادم الاختبار الصغير 10,000 مستخدم — التفاصيل والتوصيات هناك.

تغيير سلوك مقصود: رفض المصروف أو إعادته للتعديل يتطلب كتابة السبب.
كلمات السر: كما هى بدون تغيير (حماية شيتات Excel: EBDA2026).
